# Suno Downloader (公式アートワーク＆メタデータ自動埋め込み)

Suno AI（[suno.com](https://suno.com)）の楽曲URLを複数入力するだけで、曲名・アーティスト名・公式ジャケット写真を自動取得し、高音質 **MP3（320kbps）** または **M4A（ロスレスAAC）** で一括ダウンロードできるデスクトップ/Webアプリケーションです。

---

## 主な特徴

1. **複数URLの一括貼り付け対応**
   - テキストエリアに複数のSuno楽曲URLをまとめて貼り付けるだけで、楽曲IDを自動抽出してキューに追加します。
   - `https://suno.com/song/<UUID>` 形式だけでなく、CDN形式やUUID直打ちにも対応しています。

2. **曲名＆アーティスト名の自動取得**
   - Sunoの公開ページおよびメタデータ（OGP/タイトル）から楽曲タイトルとアーティスト名を自動抽出します。
   - ダウンロード前に画面上でタイトルやアーティスト名を自由に微調整・手動編集できます。

3. **公式アートワーク（ジャケット写真）の完全反映**
   - Suno公式の高解像度カバーアート（JPEG/PNG）を自動ダウンロード。
   - 音声ファイル内にアルバムアート（フロントカバー）として正規に埋め込みます。
   - Windows Media Player、iTunes、Apple Music、Walkman、スマートフォンの音楽プレーヤーで美麗な公式ジャケット写真が表示されます。

4. **形式選択（MP3 / M4A）**
   - **MP3**: 320kbpsの最高音質MP3に変換し、ID3v2（TIT2, TPE1, TALB, APIC）タグを完全埋め込み。
   - **M4A**: 元のAACストリームを無劣化で抽出し、Apple規格に準拠したMP4タグ（©nam, ©ART, ©alb, covr）を完全埋め込み。

5. **アプリ内プレビュー試聴プレイヤー**
   - ダウンロード前にブラウザ上でそのまま音源を再生・確認できるミニプレイヤーを各曲カードに搭載。

6. **ワンクリック起動（`run.bat`）**
   - ダブルクリックするだけでサーバー起動＆自動ブラウザオープン。

---

## 使い方

### 1. アプリを起動する
フォルダ内の **`run.bat`** をダブルクリックしてください。
自動的に依存ライブラリの確認が行われ、既定のWebブラウザでアプリ画面（`http://127.0.0.1:8000`）が開きます。

※ コマンドラインから手動起動する場合:
```bash
python app.py
```

### 2. URLを入力して情報を取得する
- 入力欄にダウンロードしたいSunoのURLを1行に1つ（または複数行まとめて）貼り付けます。
- **「楽曲情報を取得する」** ボタンをクリックします。
- 画面下にジャケット写真、曲名、アーティスト名のプレビューカードが並びます。

### 3. ダウンロードする
- 必要に応じて曲名やアーティスト名を編集します。
- 一括ダウンロード形式（MP3 または M4A）を選択します。
- **「すべて一括ダウンロード」** または各曲の **「ダウンロード」** ボタンをクリックします。
- 処理が完了すると、自動的に `./downloads` フォルダに保存されます。
- **「保存フォルダを開く」** ボタンをクリックすると、Windowsのエクスプローラーで保存先フォルダが即座に開きます。

---

## 動作環境・必要要件

- **OS**: Windows 10 / 11
- **Python**: 3.10 以上
- **FFmpeg**: インストール済み（システムPATHに登録済み）
- **主要Pythonライブラリ**:
  - `fastapi`, `uvicorn` (Web APIサーバー)
  - `requests`, `beautifulsoup4` (Sunoデータ取得)
  - `mutagen` (ID3v2 / MP4タグ・アートワーク埋め込み)
