# Suno Downloader (公式アートワーク＆メタデータ自動埋め込み)

Suno AI（[suno.com](https://suno.com)）の楽曲URLを複数入力するだけで、曲名・アーティスト名・公式ジャケット写真を自動取得し、高音質 **MP3（320kbps）** または **M4A（ロスレスAAC）** で一括ダウンロードできるデスクトップ/Webアプリケーションです。

---

## 主な特徴

1. **⚡ Sunoワークスペース＆Web画面の直接連携（Tampermonkey対応）**
   - Suno公式の画面上に直接「📥 ダウンロード」ボタンを追加。
   - **ワークスペース等で複数曲を選択（チェック）し、画面の「📥 選択した曲をダウンロード」を1ポチするだけ** で、URLコピー不要で直接アプリへ送信・保存できます。

2. **📋 クリップボード自動監視モード**
   - アプリの「クリップボード自動監視」をONにしておけば、ブラウザでSunoのリンクを「Ctrl+C」するだけでアプリが自動検知。
   - 「⚡ 自動保存」を併用すれば、コピーするだけで裏で即座にダウンロードまで完了します。

3. **📂 プレイリスト＆ユーザーページの丸ごと一括展開**
   - 個別曲URLだけでなく、**「プレイリストURL（`suno.com/playlist/...`）」** や **「ユーザーページ（`suno.com/@username`）」** を1行入力するだけで、中の全楽曲を自動で一括抽出してダウンロードできます。

4. **曲名＆アーティスト名の自動取得**
   - Sunoの公開ページおよびメタデータ（OGP/タイトル）から楽曲タイトルとアーティスト名を自動抽出します。
   - ダウンロード前に画面上でタイトルやアーティスト名を自由に微調整・手動編集できます。

5. **公式アートワーク（ジャケット写真）の完全反映**
   - Suno公式の高解像度カバーアート（JPEG/PNG）を自動ダウンロード。
   - 音声ファイル内にアルバムアート（フロントカバー）として正規に埋め込みます。
   - Windows Media Player、iTunes、Apple Music、Walkman、スマートフォンの音楽プレーヤーで美麗な公式ジャケット写真が表示されます。

6. **形式選択（MP3 / M4A）**
   - **MP3**: 320kbpsの最高音質MP3に変換し、ID3v2（TIT2, TPE1, TALB, APIC）タグを完全埋め込み。
   - **M4A**: 元のAACストリームを無劣化で抽出し、Apple規格に準拠したMP4タグ（©nam, ©ART, ©alb, covr）を完全埋め込み。

7. **アプリ内プレビュー試聴プレイヤー**
   - ダウンロード前にブラウザ上でそのまま音源を再生・確認できるミニプレイヤーを各曲カードに搭載。

8. **ワンクリック起動（`run.bat`）**
   - ダブルクリックするだけでサーバー起動＆自動ブラウザオープン。

---

## 使い方

### 1. アプリを起動する
フォルダ内の **`run.bat`** をダブルクリックしてください。
自動的に依存ライブラリの確認が行われ、既定のWebブラウザでアプリ画面（`http://127.0.0.1:8000`）が開きます。

---

### 2. 【おすすめ】Sunoワークスペースから1クリックで保存（案A）
1. アプリ画面右上の **「Suno画面連携 (ブラウザ拡張)」** ボタンをクリックします。
2. 案内に従って、ブラウザに Tampermonkey を追加し、**「スクリプトをインストールする」** をクリックします。
3. Suno（suno.com）のワークスペースや作成画面を開きます。
4. 保存したい曲にチェックを入れると、画面右下に **「📥 選択した○曲をダウンロード」** ボタンが出現します。
5. ボタンを押すだけで、選択した曲だけがSuno Downloaderに送られ、自動でダウンロードされます！
   （各曲カード横の「📥」ボタンから1曲ずつの即時保存も可能です）

---

### 3. 【手軽】クリップボード監視でCtrl+C連打保存（案B）
1. アプリ画面上の **「📋 クリップボード自動監視」** と **「⚡ 自動保存」** をONにします。
2. ブラウザでSunoの曲を聴きながら、曲の「リンクをコピー」またはアドレスバー等で「Ctrl+C」を押します。
3. アプリ画面を開く必要すらなく、コピーした曲が裏で次々と自動保存されます。

---

### 4. プレイリストやURL手動入力で保存（案C）
1. 入力欄に **「プレイリストURL（`https://suno.com/playlist/...`）」** や **「ユーザーページ（`https://suno.com/@username`）」**、または個別曲URLを貼り付けます。
2. **「楽曲情報を取得する」** をクリックすると、プレイリスト内の全曲が一括展開されます。
3. 一括ダウンロード形式（MP3 または M4A）を選び、**「すべて一括ダウンロード」** をクリックします。
4. **「保存フォルダを開く」** ボタンで、Windowsのエクスプローラーから保存先を即座に確認できます。

---

## 動作環境・必要要件

- **OS**: Windows 10 / 11
- **Python**: 3.10 以上
- **FFmpeg**: インストール済み（システムPATHに登録済み）
- **主要Pythonライブラリ**:
  - `fastapi`, `uvicorn` (Web APIサーバー)
  - `requests`, `beautifulsoup4` (Sunoデータ取得)
  - `mutagen` (ID3v2 / MP4タグ・アートワーク埋め込み)
